#### 대표 연구

**CKKS 암호화 추론의 판정 일관성** · 2026 졸업 연구 · [flipguard](https://github.com/hasslelee/flipguard) · 논문 심사 중  
데이터를 암호화한 채 머신러닝 추론을 할 때 CKKS 근사 오차 때문에 평문과 다른 판정이 나올 수 있는 문제를 다뤘습니다. 판정 검사 없이 고른 초기 실행 구성 68개 중 21개에서 판정 변화나 오차 기준 위반을 확인했습니다. 평문 판정 일치, 입력별 오차 한계, 명시한 128비트 보안 정책을 채택 조건으로 두는 구성 선택 절차를 설계하고 AI 코딩 도구를 활용해 Go(Lattigo)로 구현했습니다. 47개는 그대로 두고 21개만 다시 평가해 전수 비교 537회 대신 89회 평가로 구성을 골랐고, 고른 68개 구성은 별도 입력의 판정 적용 영역에서 모두 기준을 충족했습니다.

**스마트팜 원격 접속 보안** · 2025–2026 · 융합보안논문지 제1저자 · 특허 출원  
Flask와 python-fido2로 원격 접속의 Passkey 등록·인증을 구현하고, 이상 탐지 결과를 관리자에게 알리는 구조와 평가 범위를 설계했습니다. 현장 데이터 대신 공개 OT 데이터로 검증했으며, 탐지 모델 비교 실험은 팀원이 수행했습니다.

**조건부 추적 CBDC** · 2025 · CISC-W'25 제1저자 발표 · [개요](https://github.com/hasslelee/cbdc-conditional-traceability)  
Hyperledger Besu 위에서 거래를 AES-GCM으로 암호화해 기록하고, 감사 열람키를 Shamir 비밀분산으로 5개 기관에 나눴습니다. 지분 2개로는 복구되지 않고 3개로는 복구되는 것을 확인했으며, 열람 기록은 감사 원장에 남겼습니다.

**Passkey 피싱 방지 인증** · 2024 졸업작품  
python-fido2 기반 FIDO 서버와 웹 화면을 구현하고, 등록한 Passkey가 피싱 사이트에서 인증을 거부하는지 시험했습니다.
